# 图书馆噪声巡检地图

## 功能入口

### 批量导入预览

**入口位置**：左侧边栏「馆员操作」区域 → 📥 **批量导入预览** 按钮（橙色）

**权限要求**：仅馆员角色可用

## 功能说明

馆员可以先把多个巡检点的分贝记录导入到临时预览区，页面会标出：
- 🔴 **触发告警的阅览区**：分贝值 ≥ 66dB
- ⚠️ **缺字段的记录**：缺少 areaId、decibel 或区域不存在
- 🔄 **即将覆盖的旧数据**：新的分贝值与原值不同

确认导入后才会更新本地巡检点状态，取消导入时原有楼层地图、趋势卡片和提醒列表都不会被改动。

## 支持的文件格式

### JSON 格式
```json
[
    {"areaId": "A101", "decibel": 55, "note": "环境安静"},
    {"areaId": "A102", "decibel": 72, "note": "大声讨论"}
]
```

### CSV 格式
```csv
areaId,decibel,note
A101,55,环境安静
A102,72,大声讨论
```

## 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| areaId | string | ✅ | 区域ID，如 A101、A202 |
| decibel | number | ✅ | 分贝值，范围 0-120 |
| note | string | ❌ | 备注信息 |

## 操作流程

1. 切换到「馆员」角色
2. 点击左侧「📥 批量导入预览」按钮
3. 选择导入方式：
   - **加载样例数据**：点击按钮快速查看演示
   - **选择文件**：上传 JSON 或 CSV 格式文件
4. 预览区会显示统计信息和每条记录的状态
5. 检查无误后点击「✓ 确认导入」，或点击「✗ 取消导入」放弃
6. 确认导入后，系统会自动更新楼层地图、趋势卡片和提醒列表

## 样例数据

### 测试样例 1：混合正常、告警和缺字段记录

**JSON 格式**（保存为 `sample-import.json`）：
```json
[
    {"areaId": "A101", "decibel": 72, "note": "大声讨论问题"},
    {"areaId": "A102", "decibel": 48, "note": "安静"},
    {"areaId": "A201", "decibel": 68, "note": "多人交谈"},
    {"areaId": "A202", "note": "缺少分贝值"},
    {"decibel": 55, "note": "缺少区域ID"},
    {"areaId": "A301", "decibel": 85, "note": "设备噪音"},
    {"areaId": "A302", "decibel": 42, "note": ""},
    {"areaId": "A999", "decibel": 60, "note": "不存在的区域"}
]
```

**CSV 格式**（保存为 `sample-import.csv`）：
```csv
areaId,decibel,note
A101,72,大声讨论问题
A102,48,安静
A201,68,多人交谈
A202,,缺少分贝值
,55,缺少区域ID
A301,85,设备噪音
A302,42,
A999,60,不存在的区域
```

**预期结果**：
- ✅ 有效记录：5条（A101、A102、A201、A301、A302）
- 🔴 告警区域：3条（A101=72dB、A201=68dB、A301=85dB）
- ⚠️ 缺字段：3条（A202缺decibel、缺areaId、A999区域不存在）
- 🔄 将覆盖：5条（所有有效记录的分贝值与原值不同）

## 验证场景

### 场景：导入一组含高分贝和缺字段的记录，确认只有有效记录进入告警列表

**步骤**：
1. 切换到「馆员」角色
2. 点击「📥 批量导入预览」
3. 点击「📋 加载样例数据」
4. 预览区显示：
   - ✅ 有效记录：5
   - 🔴 告警区域：3
   - ⚠️ 缺字段：3
   - 🔄 将覆盖：5
5. 检查预览列表，确认：
   - A101（72dB）标记为「🔴 告警」
   - A202 标记为「⚠️ 缺字段」并显示问题说明
   - 缺少 areaId 的记录标记为「⚠️ 缺字段」
   - A302（42dB）标记为「🔄 覆盖」，显示原值和新值
6. 点击「✓ 确认导入」，在确认框中点击「确定」
7. 验证结果：
   - 楼层地图中 A101、A201、A301 显示为红色告警状态
   - 趋势卡片中「告警区域」数量增加
   - 提醒列表中新增 3 条高优先级告警（A101、A201、A301）
   - 3 条缺字段的记录未被导入，不影响任何数据

**取消导入验证**：
1. 重复步骤 1-5
2. 点击「✗ 取消导入」或点击弹窗外部关闭
3. 验证结果：
   - 楼层地图保持原有状态
   - 趋势卡片数值不变
   - 提醒列表没有新增记录

## 告警阈值

- ✅ **正常**：≤ 50dB
- ⚠️ **预警**：51-65dB
- 🔴 **告警**：> 65dB
